# STLab02 - Test Case Execution

## 1. Project Overview

This project performs test case execution for the EduCommerce application.

The project focuses on five requirements:
- REQ-01: Product availability
- REQ-02: Cart quantity
- REQ-03: Subtotal calculation
- REQ-09: Shipping calculation
- REQ-14: Empty cart integrity
